## Adım 4 — Kontrol derlemesi
`./gradlew compileDebugKotlin testDebugUnitTest` → hepsi geçmeli. Geçmezse DUR ve raporla.

## Adım 5 — Release APK (SADECE bu bilgisayarda)
1. `./gradlew assembleRelease`
2. Dosya: `app/build/outputs/apk/release/app-release.apk`

## Adım 6 — İMZA KONTROLÜ (zorunlu — atlanırsa kullanıcılar güncelleme alamaz)
`apksigner verify --print-certs app/build/outputs/apk/release/app-release.apk`
(`apksigner`, Android SDK içinde `build-tools/<sürüm>/apksigner.bat` olarak bulunur.)

**Farklıysa: HİÇBİR ŞEY YAYINLAMA, commit/push yapma, DUR ve raporla.**

## Adım 7 — Commit, push, birleştirme YOK
1. `git add app/build.gradle.kts docs/release-notes/release_notes_v1.4.0.txt`
2. `git commit -m "chore(release): v1.4.0 (build 60)"`
3. `git push origin chore/surum-1.4.0`
4. **Main'e birleştirme.** (Claude birleştirecek.)

## Adım 8 — Yayın
```
gh release create v1.4.0 app/build/outputs/apk/release/app-release.apk --target chore/surum-1.4.0 --title "v1.4.0" --notes-file docs/release-notes/release_notes_v1.4.0.txt
```
- APK dosya adı `app-release.apk` olarak kalmalı (güncelleme sistemi bu adı bekliyor). Yeniden adlandırma.
- `--generate-notes` **kullanma**. Release açıklamasına başka bir şey ekleme.
- `gh` çalışmazsa / giriş istemezse: DUR, raporla (kullanıcı elle yükleyecek). Başka yöntem deneme.
